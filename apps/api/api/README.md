# Generated

`index.js` in this directory is build output, produced from `../serverless/entry.ts` by:

```
npm run build:serverless -w @loom/api
```

It is committed so the platform can detect the function without depending on
build ordering, and regenerated on every deploy by the `buildCommand` in
`../vercel.json`. Edit `../serverless/entry.ts`, never this file.
